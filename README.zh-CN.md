# 多响应近红外校准中的目标波段并集复用

本仓库对应第五版论文，整理目标专用输入、并集输入、PLS成分候选范围和随机扩展参照的既有代码、预测、模型参数、证据记录及图件来源。原始光谱与参考标签不在公开包内，须从数据提供方取得并在本地导入。

默认程序不训练模型、不重新选谱、不下载数据，也不需要GPU。仓库将文件完整性、保存预测的指标复算、保存模型的预测核对，以及历史训练源码分开说明。

## 比较内容

| 流程 | 每个目标模型读取的输入 | PLS成分候选范围 |
|---|---|---|
| A | 本目标子集S_j | CGL 1–12；Corn 1–11 |
| B | 四目标子集的并集U | 与A相同 |
| C | 同一并集U | 1–15 |
| Dlow | 保留S_j，随机补足至U的列数 | 与B相同 |
| Dwide | 与Dlow相同的随机面板 | 与C相同 |

主随机参照为B对Dlow、C对Dwide。D匹配每模型列数及对应成分候选范围，不匹配全局采集并集、相关结构、有效自由度或搜索成本。所有响应建立独立PLS1模型；本研究不提出新选谱算法。

两个数据来源为CGL_NIR和Corn。Corn仅使用m5仪器；新增31001、31002划分仍使用同一批80个样本，不作为新增独立材料来源。原测试结果在补强设计前已经查看，执行隔离不改变事后分析身份。

## 使用步骤

在仓库根目录运行，使用Python 3.10或以上版本。

### 1 检查公开文件与保存证据

```console
python -m pip install -r requirements-recheck.txt
python scripts/verify.py
```

这一步不需要原始数据，只检查包内文件与保存记录的一致性；没有本地参考标签时，不能据此声称已经独立复算预测误差。

### 2 从提供方取得数据并本地导入

来源、下载入口和文件校验信息见[数据来源说明](DATA_SOURCES.md)。将下面两个示例路径替换为自己的MAT或提供方ZIP文件：

```console
python -m pip install -r requirements-import.txt
python scripts/import_reference_data.py --cgl "../source-data/CGL_nir.mat" --corn "../source-data/corn.mat"
```

导入器核对源数组的值及行序，生成`data/local/reference_data.npz`。该文件含原始光谱和参考标签，仅用于本地核对，不进入版本控制或公开压缩包。

### 3 执行支持范围内的全部无拟合核对

```console
python scripts/verify.py --all
```

这一步需要已导入的数据，增加保存预测指标复算、已保存参数的预测核对，以及原A/B/C固定预测重采样核对。缺少数据时会明确报告缺项，不把未执行项目算作通过。新报告写入`generated/`，不覆盖存档结果。

单项程序的可用参数可由`python scripts/recheck_metrics.py --help`和`python scripts/recheck_models.py --help`查看。保存证据核对可单独执行`python scripts/recheck_evidence.py`；原A/B/C固定预测重采样核对可执行`python scripts/recheck_resampling.py`，后者需要已导入数据。

### 4 可选重绘十个图页

```console
python -m pip install -r requirements-figures.txt
python scripts/figures/recreate_all.py
```

封存PDF/SVG在`figures/`。重绘文件另存于`generated/`，包括矢量图、预览、作图数据和可执行的图件检查，不覆盖封存图。字体和渲染器变化后仍需检查实际版面，不把数值一致自动解释为重绘文件已通过原作者的全部排版审查。

## 覆盖范围

仓库索引对应6张正文表、28张补表、主图1–4及补图S1–S3。[论文表格快照](evidence/tables/published_tables.json)保留34张表的内容，快照与从预测重新计算指标分开记录。S2有4个协调图页，因此共10个图页。范围包含原A/B/C、十次D窄/宽随机流程、两套新增Corn划分、原全谱背景、成分曲线、实际选择、精确列重合、成本和原固定预测重采样。

11月24日新增的8个D流程样本SD和8个B/A的RMSE变化也在覆盖范围内。原固定预测重采样只适用于原A/B/C，不扩展到D或新增划分。

644条流程及2576条逻辑目标模型记录包含历史复用和相互依赖的比较，不代表644次独立实验、2576个不同物理模型或新增独立样本。

## 复现能力边界

保存预测复算回答“这些预测在原参考值和既定汇总规则下，能否得到报告数值”。模型预测核对回答“这些保存参数能否恢复相应预测”。二者均不等于从头重新选谱和训练，也不提供新材料或新仪器的盲测。

历史源码和环境用于追溯。尚未验证的新设备或新软件组合下完整训练复现，不会因文件整理或哈希通过而被声明完成。详细规则见[复现说明](REPRODUCIBILITY.md)。
