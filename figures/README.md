# Frozen publication figures

This directory contains the ten frozen figure pages in editable-text SVG and
embedded-font PDF form, plus their English legends. The source figures were
generated from saved records. No raster illustration model was used to invent
quantitative results. The PDFs/SVGs are the publication reference; generated
previews and 800-dpi TIFFs are not needed for this lightweight repository.

- Main text: Figures 1, 2, 3, 4.
- Supplement: Figure S1, the four coordinated target pages of Figure S2, and
  Figure S3.

The alternative generated images are written to `generated/`, not here. See
`scripts/figures/README.md` for regeneration, font differences, and audit scope.
